Bug Bounty

Rapidex Labs operates a bug bounty program for responsible disclosure of security vulnerabilities in the deployed v3 contracts. Rewards are issued based on severity according to the CVSS scoring standard.

Responsible Disclosure Do not publicly disclose a vulnerability before reporting it privately to the Rapidex Labs security team. Public disclosure before a patch is deployed puts user funds at risk and may disqualify the submission from the bounty program.

Bounty Scope

The following are in scope for the bug bounty program:

  • All deployed Rapidex v3 Core contracts (Factory, Pool, PoolDeployer)
  • All deployed Rapidex v3 Periphery contracts (SwapRouter, NonfungiblePositionManager, QuoterV2, TickLens)
  • Periphery helper libraries (PoolAddress, CallbackValidation, TickMath)

The following are out of scope:

  • Third-party integrations or front-end interfaces
  • Theoretical attacks that require governance control or protocol admin keys
  • Issues already reported or known
  • Economic attacks that require >$1M capital to execute profitably
