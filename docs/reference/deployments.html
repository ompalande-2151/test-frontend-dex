Deployments

Official Rapidex v3 contract deployment addresses across supported networks. Always verify contract configurations before executing trades.

Verify Before Use Contract addresses differ per chain. Cross-check every address against block explorers before integrating. Using the wrong address may result in permanent loss of funds.

Fee Tiers

Rapidex v3 pools are deployed at one of three fee tiers. The same token pair can have up to three separate pools:

Fee TierTick SpacingBest For
0.05% (500)10Stablecoin pairs (e.g. USDC/USDT-equivalents)
0.30% (3000)60Standard volatile pairs (e.g. MST/USDC)
1.00% (10000)200Exotic or highly volatile pairs (e.g. MST/RAPID)
