Getting Started

Configure your development environment and smart contracts to interact directly with the Rapidex v3 protocol on the MST Network.

Connecting to MST Networks

To interact with Rapidex v3, your decentralized application or smart contracts must communicate with a node on the MST network. Developers can deploy and test their contracts on the MST Testnet before migrating to Mainnet.

Importing Interfaces

To write Solidity smart contracts that interact with the protocol, import the interface definitions directly into your project files. This allows your compiler to verify the function signatures of the deployed Rapidex contracts:

solidityimport "@rapidex/v3-periphery/contracts/interfaces/ISwapRouter.sol";
import "@rapidex/v3-periphery/contracts/interfaces/INonfungiblePositionManager.sol";
import "@rapidex/v3-core/contracts/interfaces/IRapidexV3Pool.sol";

You can reference the exact deployed addresses for the SwapRouter, Factory, and NonfungiblePositionManager on the Deployments page.
